# 反向图灵

[**打开网页试玩**](https://reverse-turing.pages.dev/) · [English](README.md) · [本地运行和部署](docs/deploy.zh-CN.md)

一个让人类伪装 AI 的网页小游戏。看一条匿名回答，猜是人写的还是 AI 写的。也可以换你来答，看看陌生人会怎么猜。

- **猜一条：** 投完票才会看到其他人的选择，以及作者自己标注的来源。
- **写一条：** 随机抽题，自己写或粘贴 AI 的回答，标注来源后匿名投进公开题库。
- **回来看看：** 在同一浏览器进入「我的回答」看票数。换设备可用保存的私用管理链接看结果或撤稿。

无账号、无积分、无榜单。简体中文和英文各有一个题库，投稿保留原文。

## 怎么看结果

开场示例由 AI 生成，投票后会注明。玩家投稿的来源由本人标注。这是个猜题游戏，不是 AI 检测器。

网站不索要姓名、邮箱或手机号。随机访客 Cookie 用来减少同一浏览器重复投票，不代表网站验证了投票者身份。投稿是公开的，不要填写个人信息；私用管理链接请自己保管。

## 开发

界面使用原生 HTML、CSS 和 JavaScript，Cloudflare Pages Worker 提供网页和接口，D1 保存回答与投票。网站本身不会调用模型，不需要 AI API Key。

使用 Node.js 24 或更新版本：

```sh
npm test
npm run build
```

测试覆盖多个访客之间的投票、中英文题库和私用管理链接。构建产物在 `dist-pages/`；本地 D1 和自托管步骤见[部署指南](docs/deploy.zh-CN.md)。
